🟤 Step 5: Collect PR Data Using GitHub API
Now, let’s collect PR data with the GitHub API! 🎯

You’ll need a GitHub Personal Access Token (PAT):

Go to Settings → Developer settings → Personal Access Tokens.
Generate a new token with repo and user permissions.
Copy the token (you’ll only see it once).
Next, use this Python script to fetch the PR data:

python
Copy
Edit
import requests

# GitHub API credentials
TOKEN = "your_github_token_here"
OWNER = "stacy"
REPO = "test-pr-tracking"

# GitHub API headers
headers = {
    "Authorization": f"token {TOKEN}",
    "Accept": "application/vnd.github.v3+json"
}

# Fetch PRs
pr_url = f"https://api.github.com/repos/{OWNER}/{REPO}/pulls"
response = requests.get(pr_url, headers=headers)
prs = response.json()

# Loop through PRs and get user data
for pr in prs:
    user_url = pr['user']['url']
    user_response = requests.get(user_url, headers=headers)
    user_data = user_response.json()
    
    print(f"PR Title: {pr['title']}")
    print(f"Username: {pr['user']['login']}")
    print(f"Location: {user_data.get('location', 'Not provided')}")
    print(f"Email: {user_data.get('email', 'Not public')}")
    print(f"Bio: {user_data.get('bio', 'No bio')}")
    print(f"GitHub URL: {user_data['html_url']}")
    print(f"Created At: {pr['created_at']}")
    print(f"Changed Files URL: {pr['url']}/files")
    print("-" * 40)
